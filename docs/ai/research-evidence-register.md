## Open evidence questions

1. Does Jobright publish a current, public source/vendor list with rights and geographic coverage?
2. Which models/providers are used for each resume, match, copilot, and autofill feature?
3. Which data is retained, for how long, and how does account deletion affect provider copies and derived features?
4. What ranking quality and geographic completeness do its public scores achieve on a blinded labeled dataset?
5. Which workflows are available without an account and in each geography/plan?

## Research method and limits

Reviewed official public product, privacy, terms and API documentation; inspected existing Graphify artifacts for targeted repository navigation, then verified code/docs. REA used an isolated unauthenticated public homepage browser capture; no credentials, private endpoints, response bodies or user information. No production database, cloud services, or account were accessed. URLs and claims should be rechecked before implementation because policies, product UI, terms, and APIs can change.
