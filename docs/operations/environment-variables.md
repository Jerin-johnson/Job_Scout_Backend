# Environment variables

Defaults and validation below come from `src/config/env.js`; values in `.env.example` are placeholders only. Required means the schema/startup path requires it, not that every integration must be enabled. Production AI startup validation adds provider/model checks. Keep secrets backend-only.

## AI and cost controls

| Variable                                          | Required                      | Default / placeholder                                    | Purpose                                                                                       |
| ------------------------------------------------- | ----------------------------- | -------------------------------------------------------- | --------------------------------------------------------------------------------------------- |
| `LLM_PROVIDER`                                    | Yes for AI                    | `groq` in schema; `gemini` in `.env.example`             | Selected default LLM provider (`anthropic`, `gemini`, `groq`).                                |
| `GEMINI_API_KEY`                                  | If Gemini selected            | empty                                                    | Gemini credential.                                                                            |
| `GEMINI_MODEL_SMALL`, `GEMINI_MODEL_STRONG`       | Yes if Gemini selected        | `gemini-3.5-flash-lite`                                  | Tier model IDs, validated against the priced catalog in production.                           |
| `GEMINI_DATA_POLICY_CLASS`                        | Optional                      | `unpaid_free_tier`                                       | Personal-data policy class; production blocks personal data unless configured `paid_api`.     |
| `GROQ_API_KEY`                                    | If Groq selected              | empty                                                    | Groq credential.                                                                              |
| `GROQ_MODEL_SMALL`, `GROQ_MODEL_STRONG`           | Yes if Groq selected          | `openai/gpt-oss-20b`, `openai/gpt-oss-120b`              | Groq tier model IDs.                                                                          |
| `GROQ_DATA_POLICY_CLASS`                          | Optional                      | `unpaid_free_tier`                                       | Personal-data policy class.                                                                   |
| `ANTHROPIC_API_KEY`                               | If Anthropic selected         | dummy development value; production placeholder rejected | Anthropic credential.                                                                         |
| `MODEL_SMALL`, `MODEL_STRONG`                     | Yes if Anthropic selected     | empty                                                    | Anthropic tier model IDs; must exist in the catalog.                                          |
| `ANTHROPIC_MODEL_SMALL`, `ANTHROPIC_MODEL_STRONG` | Optional legacy config        | `claude-3.0-100k`                                        | Parsed but provider adapter uses `MODEL_SMALL` / `MODEL_STRONG`; do not rely on these values. |
| `ANTHROPIC_DATA_POLICY_CLASS`                     | Optional                      | `unpaid_free_tier`                                       | Parsed but effective Anthropic policy is currently `paid_api` in `aiStartupValidation.js`.    |
| `AI_ALLOW_MOCKS`                                  | Optional                      | `false` in schema; `.env.example` enables local mocks    | Explicit dev/test mock switch; production startup rejects true.                               |
| `AI_BLOCK_UNPAID_PERSONAL_DATA`                   | Optional                      | `true`                                                   | Blocks personal-data features in production unless policy class is paid API.                  |
| `AI_KILL_SWITCH`                                  | Optional                      | `false`                                                  | Global model/embedding kill switch.                                                           |
| `AI_PROVIDER_MAX_RETRIES`                         | Optional                      | `1`                                                      | Maximum classified transient retries (0–3); timeouts are not retryable.                       |

| `AI_MONTHLY_ALLOWANCE_SHADOW_MODE`                | Optional                      | `true`                                                   | Logs monthly allowance would-blocks; does not enforce monthly limits.                         |
| `AI_MONTHLY_ALLOWANCE_SHADOW_RATIO`               | Optional                      | `0.25`                                                   | Fraction of plan price used for shadow calculations.                                          |
| `EMBEDDING_PROVIDER`                              | Optional                      | `openai`                                                 | `openai` or `voyage`.                                                                         |
| `OPENAI_API_KEY`                                  | If OpenAI embeddings selected | placeholder in `.env.example`                            | Embedding credential (also parsed by the environment schema).                                 |
| `OPENAI_EMBEDDING_MODEL`                          | Optional                      | `text-embedding-3-small`                                 | OpenAI embedding model.                                                                       |
| `OPENAI_EMBEDDING_DIMENSION`                      | Optional                      | `1536`                                                   | Requested dimension, 1–3072.                                                                  |

| `VOYAGE_EMBEDDING_MODEL`                          | Optional                      | `voyage-large-2-instruct`                                | Voyage embedding model.                                                                       |
| `VOYAGE_EMBEDDING_DIMENSION`                      | Optional                      | `1024`                                                   | Requested dimension, 1–4096.                                                                  |
| `MOCK_INTERVIEW_PREMIUM_DAILY_LIMIT`              | Optional                      | `3`                                                      | Premium starts per quota day.                                                                 |

| `MOCK_INTERVIEW_RETENTION_DAYS`                   | Optional                      | `90`                                                     | Interview-session retention.                                                                  |

## Core service and security

| Variable                                                       | Required                                                | Default / placeholder                    | Purpose                                                         |
| -------------------------------------------------------------- | ------------------------------------------------------- | ---------------------------------------- | --------------------------------------------------------------- |
| `NODE_ENV`                                                     | Optional                                                | `development`                            | Runtime mode.                                                   |
| `PORT`                                                         | Optional                                                | `4001`                                   | HTTP API port.                                                  |
| `HOST`                                                         | Optional                                                | `0.0.0.0`                                | HTTP bind host.                                                 |
| `WEB_ORIGIN`                                                   | Optional                                                | `http://localhost:3000`                  | Allowed browser origin.                                         |
| `COOKIE_DOMAIN`                                                | Optional                                                | `localhost`                              | Cookie domain; localhost omits explicit domain.                 |
| `TRUST_PROXY`                                                  | Optional                                                | `1`                                      | Express proxy trust setting.                                    |
| `JWT_ACCESS_SECRET`                                            | Required                                                | replace with random 32+ character secret | Access-token signing secret.                                    |
| `JWT_REFRESH_SECRET`                                           | Required                                                | separate random 32+ character secret     | Refresh-token signing secret.                                   |
| `RESUME_ENCRYPTION_KEY`                                        | Required                                                | 64-character zero placeholder only       | Replace with 32 random bytes encoded as hex/base64.             |
| `MONGODB_URI`                                                  | Optional locally; production required operationally     | `mongodb://localhost:27017/jobscout`     | MongoDB connection.                                             |
| `REDIS_URL`                                                    | Optional locally; required for production queues/quotas | `redis://localhost:6379`                 | Redis/BullMQ connection.                                        |
| `REDIS_HOST`, `REDIS_PORT`, `REDIS_USERNAME`, `REDIS_PASSWORD` | Optional legacy, currently unused                       | none                                     | Commented legacy Redis fields; implementation uses `REDIS_URL`. |
| `SUPER_ADMIN_EMAIL`                                            | Optional                                                | empty                                    | Optional bootstrap super-admin identity.                        |
| `APPLICATION_STALE_DAYS`                                       | Optional                                                | 7 in `.env.example`; code fallback 7     | Stale application attention interval.                           |

## Storage, payments, email, observability, and sources

| Variable                                                                                                       | Required                                           | Default / placeholder                                              | Purpose                                                                                                                        |
| -------------------------------------------------------------------------------------------------------------- | -------------------------------------------------- | ------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------ |
